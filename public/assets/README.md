# Ассеты мини-аппа

Сюда положи 5 растровых файлов (PNG). Без них приложение не падает — рисуются
код-плейсхолдеры (логотип-компас, SVG-небо на splash, эмодзи-маскоты), но с
файлами выглядит как задумано.

| Файл | Где используется | Рекомендация |
|------|------------------|--------------|
| `bot-icon.png` | логотип на splash, favicon | квадрат ≥256×256, с прозрачностью или фоном |
| `mascot-beginner.png` | уровень «Росток» (онбординг, прогресс) | PNG с прозрачным фоном, ~512×512 |
| `mascot-practitioner.png` | уровень «Ракета» | PNG с прозрачным фоном, ~512×512 |
| `mascot-advanced.png` | уровень «Мозг» | PNG с прозрачным фоном, ~512×512 |
| `splash-hero.png` | фон splash-экрана | вертикальный ~1080×1920; заголовок/кнопка лежат в ВЕРХНЕЙ светлой зоне — низ может быть любым, переход в фон сглаживается градиентом кодом |

Имена файлов менять нельзя — они зашиты в коде. Положил файлы → просто перезагрузи
мини-апп, ничего пересобирать не нужно.
