# Ясно • AI-Академия

Telegram Mini App для growth-команды Ясно: внутренний AI-наставник, который учит применять AI в работе.

**Три кита:**
- **Принеси задачу** — опиши рутину, получи готовый AI-воркфлоу (шаги, промт, инструмент, оценка экономии времени). Через несколько дней бот спросит, сэкономило ли время → метрика «Эффект».
- **Микро-уроки** — 3–5 минут, под роль (9 ролей) и уровень (новичок/практик/продвинутый). База реальных уроков + догенерация gpt-5.5.
- **Радар новинок** — свежие AI-инструменты с разбором «как применить в твоей роли».

Плюс: стрики, бейджи, лидерборд и экран «Эффект» (сколько часов в неделю высвободила команда).

## Стек
Node.js (≥22.13, используется встроенный `node:sqlite`) + Express, ваниль-JS фронт (без бандлера), SQLite, OpenAI API (модель из `OPENAI_MODEL`), nginx + PM2 + certbot на VPS.

## Запуск локально
```bash
npm install
cp .env.example .env   # для dev можно ALLOW_DEV_NO_AUTH=true
npm run dev            # http://localhost:3000/Yasno-growth-bot/
```

## Структура
```
server/        Express: API, Telegram-webhook, LLM-прокси, шедулер пушей
  content/     База уроков (JSON по ролям) и радар новинок
public/        Mini App (ваниль, ES-модули, относительные пути)
  assets/      5 растровых ассетов владельца (см. PROGRESS.md)
deploy/        nginx, PM2 ecosystem, setup.sh, инструкции webhook
scripts/       Проверки и Playwright-скриншоты
```
